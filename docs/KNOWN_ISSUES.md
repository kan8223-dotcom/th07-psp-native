# 既知の不具合・未検証項目

## 実機で報告された処理落ち

- 4面から処理負荷が大きくなります。
- プリズムリバー戦付近の「霊界の門」を含む3D背景が特に重くなります。
- 5面の3D階段背景も同様に重くなります。
- スペルカードで2D背景へ切り替わると一気に軽くなるため、弾や音声より3D背景描画経路の負荷が主因とみています。

このベータでは症状を記録するところまでとし、3D背景の最適化は次の作業に回しています。

## v0.1.0-betaで修正し、実機再確認が必要な項目

- 妖夢撃破後、6面へ入らずXMBへ戻る問題。
  面切替時に未使用テクスチャ領域を解放し、6面登録を再試行するようにしました。
- 自機側・敵側の会話立ち絵の一部が、PSP画面の最上段へ横一列・1ピクセルだけ出る問題。
  立ち絵だけ物理画面の最上段を覆わないよう座標とUVをクリップしました。

## その他

- PSP-1000の32MB RAMには未対応です。
- 1面から6面、エンディング、スタッフロール、タイトル復帰までの完全な実機通し確認は、
  このベータ修正後にはまだ完了していません。
- セーブデータとリプレイの互換性・完全性は保証していません。
- PPSSPPで正常でも、Memory Stick I/O、CFW、MECC、メモリ制約に関する実機固有問題が残る場合があります。
