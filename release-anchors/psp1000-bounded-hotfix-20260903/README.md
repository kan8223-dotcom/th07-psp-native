# PSP-1000 bounded hotfix runtime anchor (2026-09-03)

This is the 32 MiB runtime embedded in the updated v1.0.0-rc1 unified
pre-release. It keeps the fixed udLUNA and built-in demo paths unchanged while
reserving the existing bounded Enemy arena for normal play and unmeasured
main-route replays. The direct regression was checked on a physical PSP-1000;
the ending has not yet been verified on PSP-1000. No original game data,
generated XMB media, or replay is embedded.
